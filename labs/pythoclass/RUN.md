```powershell

python labs/pythoclass/check_examples.py
python labs/pythoclass/05-file-csv/solution.py
python labs/pythoclass/09-linear-pca/solution.py
```

- Bộ kiểm tra biên dịch cú pháp của 13 script và chạy script có đủ thư viện. Thiếu thư viện được ghi SKIP.

- Script chỉ đọc CSV, không sửa repo nguồn. Lab 13 thực hành Git bằng tay, script không tự chạy lệnh Git.
