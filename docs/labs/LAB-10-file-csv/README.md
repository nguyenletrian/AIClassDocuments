# Lab 10 — CSV Student Grades

Read [LAB_EN_SOLVED.md](LAB_EN_SOLVED.md) for six English prompts and solutions below each requirement. [SOLUTION_ANNOTATED.py](SOLUTION_ANNOTATED.py) is the complete thoroughly commented application. [students.csv](students.csv) contains 10 synthetic learners.

Run `python SOLUTION_ANNOTATED.py --demo` for safe non-interactive tests. Run `python SOLUTION_ANNOTATED.py` for the interactive menu. Both use Python's standard library only. The demo never overwrites the sample CSV; interactive mode changes the file only when Save is chosen.
